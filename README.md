## 1. Aim
To perform various data mining operations using Orange Data Mining, including data cleaning, data reduction, data transformation, association rule mining, statistical analysis, regression, outlier detection, and K-means clustering.

## 2. Software Required
- **Software:** Orange Data Mining
- **Platform:** GitHub
- **Dataset Format:** CSV and other supported formats

## 3. Dataset
The following datasets are included in this repository for performing different data mining operations:

- `iris.csv` – Used for clustering and data analysis.
- `iris.arff` – Iris dataset in ARFF format.
- `wine.csv` – Used for data analysis and preprocessing.
- `diabetes.csv` – Used for regression and statistical analysis, depending on the available attributes.
- `transactions.csv` – Used for association rule mining.

## 4. Workflow
The general workflow for data mining experiments in Orange is:

`File → Data Processing → Analysis/Modeling → Visualization/Output`

## 5. Procedure
1. Open Orange Data Mining.
2. Load the appropriate dataset using the File widget.
3. Connect the dataset to the required processing widget.
4. Configure the settings according to the experiment.
5. Connect the output to suitable visualization or analysis widgets.
6. Examine the results and save the workflow as an `.ows` file.
7. Capture screenshots of the workflow and output for documentation.

## 6. Output
The output of each experiment may include processed datasets, statistical summaries, association rules, regression results, detected outliers, clustering results, and visualizations.

## 7. Result
Various data mining techniques are demonstrated using Orange Data Mining. The experiments help develop an understanding of data preprocessing, statistical analysis, association rule mining, regression, outlier detection, and clustering.

## Conclusion
This repository contains datasets, Orange workflow files, and visual references for data mining practicals. It serves as a record of the experiments and their implementation using Orange Data Mining.
